# Homework 17

## Реализованная функциональность

- Создан класс `Product` для представления товара.
- Класс `Product` содержит название, описание, цену и количество товара.
- Создан класс `Category` для представления категории товаров.
- Класс `Category` содержит название, описание и список товаров.
- Реализован подсчёт количества созданных категорий.
- Реализован подсчёт количества товаров в категориях.
- Реализована проверка типов товаров при добавлении в категорию.
- Реализовано сложение товаров одного типа с помощью магического метода `__add__`.
- Добавлена обработка ошибки `TypeError` при попытке сложить товары разных типов.
- Создан класс `Smartphone`, наследующийся от `Product`. Он содержит характеристики эффективности, модели, объёма памяти и цвета.
- Создан класс `LawnGrass`, наследующийся от `Product`. Он содержит страну-производителя, срок прорастания и цвет.
- Обновлён файл `main.py` для демонстрации работы классов и наследования.
- Написаны тесты для классов `Product`, `Category`, `Smartphone` и `LawnGrass`.

## Запуск проекта

Для запуска основной программы выполните:

```bash
poetry run python main.py
```

Для запуска тестов с проверкой покрытия кода выполните:

```bash
poetry run pytest --cov=src/homework_17
```
